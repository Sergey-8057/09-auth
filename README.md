# 📝 NoteHub — Personal Note Management App

**NoteHub** is a personal note management web application with user registration and login.  
It allows users to create, edit, delete, and filter notes, as well as save drafts and view note details in modals.  

Built with **Next.js**, **React**, **TypeScript**, **Zustand** (state management), **React Query**, and **Axios** for API handling.  
The project is deployed on **Vercel**.

---

## 🧰 Tech Stack

- **Frontend / Fullstack:** Next.js · React · TypeScript  
- **State & API:** Zustand · React Query · Axios  
- **Styling:** CSS
- **Tools & Config:** Vite · Git · GitHub · ESLint · Prettier

---

## 💡 Features

- User registration and login  
- Create, edit, delete notes  
- Tag filtering and keyword search  
- Draft saving functionality  
- Modals for viewing note details  
- Pagination for note lists  
- Responsive and modern UI
